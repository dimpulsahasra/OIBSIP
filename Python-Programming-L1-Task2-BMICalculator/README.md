# BMI Calculator — Python Programming Internship

## Project Overview
This project is a Python-based BMI (Body Mass Index) Calculator developed as part of the Oasis Infobyte Python Programming Internship.

## Features
- Accepts weight in kilograms and height in meters.
- Calculates BMI using the formula: BMI = Weight / (Height × Height).
- Classifies BMI as Underweight, Normal, Overweight, or Obese.
- Validates invalid and negative inputs.
- Displays BMI rounded to two decimal places.

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python bmi_calculator.py`.
5. Enter your weight in kilograms and height in meters when prompted.
